自带表情：以 [名称] 插入消息框
1. 登录后，在左侧打开一位好友的一对一聊天。
2. 选择“文字/表情”。只发文字也使用这个模式，不需要读取表情。
3. 点击“读取表情”。程序从官方面板及名称预览读取真实代码，例如 [捂脸]、[微笑]；不点击表情发送，不使用“自带表情 1”等假名称。
4. 将光标放在下方消息输入框的目标位置，再点击“插入表情”。
5. 每次点选缩略图，立即插入对应的 [名称]；选择窗口保持打开，可以连续选择不同表情，也可以反复选择同一个。
6. 选好后点击“完成”，回到消息输入框。可以继续输入文字、移动光标、删除或手动输入表情代码。
7. 如果消息框中选中了文字，点选表情将替换这段选中文字；300 字上限按完整表情代码计算。
8. 示例：你好[捂脸][微笑][捂脸]。发送按输入框的实际内容与顺序执行，不会在末尾额外追加一个旧表情。
9. 可以只输入多个表情代码，例如 [捂脸][捂脸]。原有每日防重复、草稿保留和发送前核对不变。
10. 旧版已选自带表情若保存了明确的 [名称]，首次载入时迁移到输入框；重复加载不会再次追加。
11. 读取范围为当前账号官方网页可加载的自带表情；名称无法确认的图标不生成猜测代码，日志会提示未识别数量。
12. 程序保存并发送你编辑的代码文本。实际渲染效果与消息送达由抖音决定。
13. 首次读取成功后自动保存到 %LOCALAPPDATA%SparkDeskuiltin-emoji-cache.json。下次启动会自动载入，可直接点击“插入表情”，无需重新读取。
14. 需要更新时再次点击“读取表情”：按 [名称] 去重，将新表情追加到本地文件；同名表情可更新缩略图地址。
15. 官方面板不再出现的旧表情仍保留，读取空列表也不会清空缓存。文件损坏时保留原文件，不以不完整结果覆盖。
16. 本地缓存仅含自带表情代码和缩略图地址，不包含账号收藏表情包或登录资料；缩略图未加载时仍可按 [名称] 选择。

收藏表情包（保持原有方式）
1. 切换到“收藏表情包”，点击“读取表情”，再点击“选择表情包”。
2. 选取一个账号收藏表情；选择本身不会发送。
3. 按原方式扫描、勾选好友后发送。每位目标收到一个已选收藏表情，不附带消息框文字，也不是图片网址。
4. 收藏表情仅读取当前网页版显示的条目；手机端未同步的收藏不会编造。
5. 此模式仍每次选择一个收藏表情包，不含本地上传或自动添加收藏；自带表情的连续插入功能不改变它。

怎么打开
1. 将整个压缩包解压到一个文件夹。
2. 双击“火花助手.exe”。旁边的 DLL 文件请保持在同一个文件夹内。
3. 在软件左侧显示的抖音官方页面完成登录，可使用页面提供的扫码方式。
4. 在右侧输入自定义消息，默认勾选“已点燃火花”“正在重燃”“灰色 / 未点燃”“即将消失”。
5. 点击“开始续火”。也可以先点“扫描火花”，取消勾选不想发送的好友，再发送。

新增：自选好友模式
1. 勾选“自选好友 · 扫描全部单聊”。
2. 点击“扫描全部”，列出可识别的一对一会话，包括没有火花标记的好友。
3. 默认只勾选“最近 30 天有联系，并且互相关注”的好友。超过 30 天无联系、未互关，或信息无法确认的好友默认不勾选，但仍列在名单里，可以手动选择；支持“全选”“清空”。
4. 点击“发送勾选好友”。只给勾选的会话发送当前自定义消息，不会自动发送给其他人。
5. 没勾选任何人时不发送。发送前重新扫描不会把新出现的人自动加入勾选名单。
自选模式不要求目标有火花，但仍核对聊天身份、保留草稿、按“每日防重复”开关决定是否跳过当天已尝试的好友。
默认筛选按照“近 30 天联系”与“互相关注”同时成立判断；“一个月”按滚动 30 天计算。
联系时间来自官方会话列表时间；不会拿消息正文或昵称中的日期判断。
只有日期、恰好落在 30 天边界，或时间/互关状态无法识别时，默认不勾选。
互关依据明确关系标记、已适配的官方单聊火花组件条件，或聊天资料卡显示；不执行关注或取消关注。
手动勾选/取消、全选/清空会覆盖默认规则，在同一模式下再次扫描时保留。
扫描完成后，内置抖音会话列表和右侧好友名单都会回到最上方。
名单第二行显示筛选原因；悬停可查看最近会话时间与状态说明。
两种模式切换、重新加载登录页面或重启软件时，会清空自选名单；需重新扫描勾选。

这是独立的 Windows 软件，不需要 Tampermonkey、不需要浏览器插件、不需要 Python 或 Node.js。
软件内置 WebView2 显示抖音官方登录页面；不是接管已经打开的抖音 Windows 客户端，也不会导入外部浏览器的 Cookie。

系统要求
- Windows 10/11 64 位。
- .NET Framework 4.8。
- Microsoft Edge WebView2 Runtime。
- 需要正常访问抖音网页的网络连接。

如果启动提示缺少 WebView2，可使用微软官方安装入口：
https://developer.microsoft.com/microsoft-edge/webview2/
本软件已附带 WebView2 SDK 绑定 DLL，但没有捆绑完整的浏览器运行时。

新版界面
- 深色圆角卡片，统一按钮层级与留白。
- 双行好友名单，火花状态标签、默认筛选原因、已选人数。
- 好友名单按像素平滑滚动，只绘制可见行；支持滚轮、滚动条和键盘上下移动，重新扫描后回到顶部。
- 右下角增加“运行日志”标题，日志区加高，任务完成摘要保留在日志中。
- 支持高 DPI 缩放，并验证最小窗口下输入区与名单仍可用。

发送结束提示
- 本批全部点击发送后：日志提示“发送任务完成：本次勾选的 X 位好友均已点击发送”。
- 有每日防重复、已有草稿或名单变化时：分别显示点击发送、跳过、当前列表未找到人数。
- 没有可发送对象时显示“本次未发送”及原因；手动停止或异常中断不会误报全部完成。
- 汇总表示程序完成本批页面操作，不把点击发送当作已经送达或火花已续上。

主要功能
- 软件内登录并保留本地登录资料。
- 自定义消息，支持换行，最多 300 字符。
- 扫描可加载的私信会话列表，识别已适配的火花状态。
- 四类火花都可进入扫描名单：已点燃、正在重燃、灰色/尚未点燃/可重燃、即将消失的倒计时火花。
- 自选好友模式列出全部可识别的一对一会话，只发送你勾选的人。
- 名单勾选排除、发送间隔、单次人数上限。
- 可选每日发送尝试去重、保留已有草稿、异常停止、停止按钮、Esc 停止。
- 同一 Windows 会话只允许一个正式软件实例。
- 本地保存配置和记录；保存成功确认后才会继续点击发送。
- 导出当前运行日志。

判断范围
- “正在重燃”只识别官方火花组件中明确的重燃中文字。
- 有火花识别已适配的非灰色官方图标与天数；未知特殊图标不猜测。
- 灰色图标、“尚未点亮”“可重燃”等归入“灰色 / 未点燃”，不再从名单里遗漏，也不把它们误标为重燃中。
- “2天后消失”“即将熄灭”等火花组件内的倒计时提示归入“即将消失”，名单中会显示已识别的原提示。
- 群聊、重复昵称、身份不清的会话仍跳过。自选模式中，无火花的单聊也可进入名单；默认勾选只取决于最近联系时间和互关关系。
- 自动模式从火花组件读取状态，不把聊天正文中的“消失”“火花”等词当作系统标记。
- 扫描范围是私信列表中能够加载的会话，不是完整关注关系或全好友数据库。

数据保存位置
%LOCALAPPDATA%\SparkDesk\
- state.bin：设置及发送尝试记录，使用 Windows 当前用户 DPAPI 加密。
- state.bin.bak：上次设置备份。
- builtin-emoji-cache.json：自带表情代码及缩略图地址，重启直接读取，再次扫描只增不删。
- builtin-emoji-cache.json.bak：自带表情缓存上次成功写入的备份。
- WebView2：抖音独立登录资料目录。
数据不上传到自建服务器。程序不读取或导出登录密码、Cookie。
清除该文件夹会同时清除登录资料和防重复记录。需要当天再次发送时，可取消勾选“每日防重复”，不用删除记录。

每日防重复开关
- 默认勾选：同一好友当天已尝试发送的会跳过。
- 取消勾选：再次点击发送时，可对当天已发送的好友重复发送。
- 关闭后仍保存每次尝试；重新勾选立即按已有记录防重复。
- 适用于自动 / 自选、文字、自带表情和收藏表情包。
- 点击“保存设置”或开始任务会保存开关状态，重启后保留。

防重复的边界（开关开启时）
- 使用本地日期；不是跨设备云端去重。
- 页面没有公开会话 ID 时，用昵称加头像路径建立会话身份。改名、换头像可能改变身份键。
- 未能识别账号时，记录按该内置浏览器资料共用。切换账号可能导致保守跳过。
- 不确定结果也记为当天已尝试，不会自动重试。
- 单次人数超过上限时整批不开始发送，不会偷偷截断。
